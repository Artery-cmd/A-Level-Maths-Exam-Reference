Paper 1 — Pure Mathematics (2 hrs, 100 marks)

Algebra & Functions

  • Factor theorem: f(a)=0 ⟹ (x−a) is a factor
  • Partial fractions — 3 types: distinct, repeated, improper
  • Completing the square → min/max and vertex form
  • Modulus graphs: reflect below x-axis, solve with ±
  • Inverse functions: swap x,y, rearrange. Domain of f⁻¹ = range of f
  • Transformations: y=f(x+a) shifts left, y=f(ax) squashes

Coordinate Geometry

  • Circle: (x−a)²+(y−b)²=r², centre (a,b), radius r
  • Tangent ⊥ radius at point of contact
  • Perpendicular bisector of any chord passes through centre
  • Parametric → Cartesian: eliminate parameter t
  • Parametric dy/dx = (dy/dt) ÷ (dx/dt)

Sequences & Series

  • Arithmetic: nth = a+(n−1)d, Sn = n/2·(2a+(n−1)d)
  • Geometric: nth = arⁿ⁻¹, Sn = a(1−rⁿ)/(1−r)
  • S∞ = a/(1−r) — only valid when |r| < 1
  • Binomial (1+x)ⁿ — valid for |x| < 1, always state this
  • For (a+bx)ⁿ: factor out aⁿ first, then expand (1+bx/a)ⁿ

Calculus

  • Chain, product, quotient rules — know all three cold
  • Implicit: d/dx(y²) = 2y·dy/dx (chain rule)
  • Integration by parts: ∫u dv = uv − ∫v du (LATE)
  • Reverse chain rule: ∫f'(x)/f(x) dx = ln|f(x)|+c
  • Change limits when substituting in definite integrals
  • Area between curves: ∫(top − bottom) dx
  • Always add +c on indefinite integrals

Proof & Logarithms

  • Contradiction: assume opposite, derive impossibility
  • Counterexample: one example is enough to disprove
  • Log laws: log(ab)=loga+logb, log(a/b)=loga−logb, log(aⁿ)=n loga
  • Change of base: logₐb = lnb/lna
  • eˡⁿˣ = x and ln(eˣ) = x

Numerical Methods

  • Sign change → root in interval (show f(a)<0 and f(b)>0)
  • Iteration: xₙ₊₁ = g(xₙ) — apply repeatedly until convergence
  • Newton-Raphson: xₙ₊₁ = xₙ − f(xₙ)/f'(xₙ)
  • Trapezium rule: h/2·[y₀+yₙ+2(y₁+…+yₙ₋₁)]
  • Trapezium: underestimate if curve is concave up, overestimate if concave down
Paper 2 — Pure + Mechanics Section B (2 hrs, 100 marks)

Kinematics (SUVAT)

  • Always state positive direction at top of working
  • g = 9.8 ms⁻² unless told otherwise (not 10)
  • At maximum height: v = 0
  • Distance ≠ displacement if direction changes — split and add |areas|
  • v-t graph: gradient = acceleration, area = displacement
  • SUVAT only for constant acceleration — use calculus if variable

Forces & Newton's Laws

  • F = ma — resolve forces first, THEN apply
  • Draw force diagram before writing any equations
  • Inclined plane: N = mg cosθ, component along = mg sinθ
  • Friction: F = μN (at limiting equilibrium / sliding)
  • Connected particles: same a, write separate F=ma for each, add to find a then sub back for T

Moments & Equilibrium

  • Moment = F × perpendicular distance from pivot
  • Equilibrium: ΣF = 0 AND Σmoments = 0
  • Take moments about a point to eliminate unknowns at that point
  • Uniform rod: weight acts at midpoint
  • Clockwise and anticlockwise moments must balance

Modelling assumptions

  • Particle: point mass, no size, no rotation, air resistance ignored
  • Smooth surface: no friction (F = 0)
  • Light string/rod: mass = 0
  • Inextensible string: same acceleration throughout system
Paper 3 — Pure + Statistics Section B (2 hrs, 100 marks)

Statistical Distributions

  • Binomial B(n,p): mean=np, variance=np(1−p)
  • Normal N(μ,σ²): standardise Z=(X−μ)/σ
  • Sample mean distribution: X̄ ~ N(μ, σ²/n)
  • Normal approx to binomial: use continuity correction ±0.5
  • Know your Casio: Normal CD, Inverse Normal, Binomial CD/PD

Hypothesis Testing

  • Define H₀ and H₁ using μ or p before anything else
  • Two-tailed test: halve the significance level for each tail
  • State test statistic distribution under H₀
  • Compare p-value to α, or check if observed value is in critical region
  • Conclusion must be in context — not just "reject H₀"
  • "Insufficient evidence to reject H₀" ≠ H₀ is true

Correlation & Regression

  • PMCC r: −1 ≤ r ≤ 1. r=0 means no linear correlation
  • Hypothesis test for ρ: H₀: ρ=0, compare |r| to critical value
  • Regression line y=a+bx: b = rate of change of y per unit x
  • Don't extrapolate beyond the data range
  • Correlation does not imply causation — state this if relevant

Sampling & Data

  • Simple random: every member equally likely
  • Stratified: proportional sub-group — n × (group/total)
  • Systematic: every kth member, k = population ÷ sample size
  • Outlier: > Q3+1.5×IQR or < Q1−1.5×IQR
  • Skew: +ve → mean > median, −ve → mean < median
Universal exam technique — all three papers

Every question, every time

  • Read the last line of the question first — know what's being asked
  • Underline: "exact", "show that", "hence", "in context", "state"
  • "Show that" — work from given info towards the target, never backwards
  • "Hence" — you MUST use the result from the previous part
  • Mark count = number of steps. 6 marks = 6 things to write
  • Never leave a blank — write a method attempt for method marks
  • Cross out (don't erase) work you don't want marked
  • Only round at the very end — carry exact values throughout
  • Check answer makes sense (negative time, probability >1 = error)

Proof by induction
4-step structure — always the same
1
Base case: verify result holds for n=1
2
Assumption: assume true for n=k — write out the statement explicitly
3
Inductive step: prove for n=k+1 using the assumption
4
Conclusion: "True for n=1; if true for n=k then true for n=k+1; by PMI true for all n∈ℤ⁺"
Σr = n(n+1)/2     Σr² = n(n+1)(2n+1)/6     Σr³ = [n(n+1)/2]²

Hypothesis testing — full 5-step method
Every test follows the same structure
1
Define: state what μ or p represents in the context of the question
2
Hypotheses: H₀: μ=… and H₁: μ>… / μ<… / μ≠…
3
Test statistic: state its distribution assuming H₀ is true
4
Calculate: p-value OR critical region
5
Conclude in context: "There is/is not sufficient evidence to suggest that [original claim]…"
Two-tailed: halve α for each tail  ·  One-tailed: full α on one side
